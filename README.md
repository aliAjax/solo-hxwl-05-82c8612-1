# hxwl-05 水族箱水质监测

多鱼缸水质趋势、换水和异常指标提醒

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5105

## 功能

- **新增鱼缸记录**：录入缸型（草缸/海缸/三湖缸/繁殖缸）、水温、pH、氨氮、硝酸盐、换水量和备注
- **编辑记录**：列表中点"编辑"回填表单，修改缸型或指标后保存写回同一条记录（保留记录时间），取消不写入；列表、指标卡、趋势图和本地存储同步更新
- **本地持久化**：记录保存在浏览器 localStorage，刷新后仍在；首次打开自动写入 3 条示例记录
- **指标超限提醒**：水温 22–28°C、pH 6.5–8.5、氨氮 ≤0.25ppm、硝酸盐 ≤40ppm，超限记录会在顶部横幅和记录卡片上标红提醒
- **趋势视图**：按时间绘制指标变化曲线，每个缸型一条线；可切换水温/pH/氨氮/硝酸盐，超限点标红放大，安全阈值以虚线标出；跟随当前筛选，筛选条件和所选指标刷新后保留
- **筛选**：按缸型筛选，指标卡、趋势图、记录列表、超限提醒和导出都跟随当前筛选条件
- **导出 CSV**：按当前筛选条件导出，带 BOM 头（Excel 打开中文不乱码），文件名含筛选条件和日期
- **删除记录**：单条删除，本地存储同步更新
- 指标卡实时统计：记录总数、平均 pH、氨氮峰值、硝酸盐均值
